# Media Dock 3.0.2

Media Dock 3.0.2 is a stable maintenance release focused on explicit runtime maintenance, faster network-media preparation, safer Cookie refreshes, and accurate startup feedback.

## Runtime maintenance

- Settings now checks yt-dlp and Deno versions without changing installed files, then shows available versions and explicit update actions.
- Users can download from the official GitHub Release URL or through the default/user-supplied HTTPS GitHub mirror.
- GitHub's official API remains authoritative for versions, asset sizes, and SHA-256 digests; mirror downloads must pass the same integrity and executable-version checks before atomic activation.
- GitHub API requests now carry explicit Media Dock headers, fixing the Electron-only HTTP 403 seen during real macOS testing.
- This control maintains download runtimes only; it no longer presents itself as a Media Dock product updater.

## Startup and network-media responsiveness

- A transient startup window reports seven real initialization gates and derives its percentage only from completed work.
- Source inspection and quality detection reuse one successful yt-dlp metadata result instead of immediately repeating the same network process.
- Inspection ignores user-level yt-dlp configuration and keeps single-video metadata requests out of playlist expansion, reducing avoidable delays on Windows.

## Authentication and download guidance

- Updating Cookies validates and stages the new MediaCookies package before replacing the previous Authentication Profile and removing its old private files.
- An invalid replacement preserves the current profile, while queued or running tasks that use it block replacement until they finish or are cancelled.
- Expired-Cookie failures are localized into actionable Simplified Chinese and English guidance.
- Download-size estimates follow the formats yt-dlp will actually select and report unknown when reliable size data is unavailable.
- The main navigation now describes the processing workspace as download tasks rather than the more abstract creation wording.

## Per-task support logs

- A task in **Needs Attention** now offers its own local **Export Task Log** action in Task Center.
- The report keeps bounded failure evidence for that task, including the application, platform, bundled runtimes, current stage, product problem, and sanitized process output.
- Cookie values, authentication credentials and profile identifiers, full media URLs, task titles, user paths, and downloaded media are excluded.
- Export is always initiated by the user and saved locally; Media Dock does not upload the report automatically.

## Packaging and platform trust

- Media Dock 3.0.2 is a final Stable source and product release.
- The native candidates bundle yt-dlp `2026.07.04` and Deno `2.9.5`, matching their latest official releases at build time.
- Native Windows x64 and macOS arm64 workflows build and verify the portable ZIPs, bundled runtimes, startup probes, Unicode/spaced data paths, and SHA-256 checksums.
- The repository still has no Windows Authenticode / Microsoft Trusted Signing credential or Apple Developer ID / notarization credential. Public binaries therefore remain explicitly labeled **Unsigned Developer Preview** and must not be represented as universally trusted platform packages.
